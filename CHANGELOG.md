# Changelog

All notable version updates are recorded here.

## [1.0.0] - 2026-05-07

### Added
- Neo-Brutalist minimalist UI redesign
- New Neo-Brutalist color system
- Rule of thirds grid toggle
- AI composition scoring system
- Real-time guide arrow animations
- Minimalist capture button design

### Improved
- Unified dark theme at #0D0D0D near-black background
- UI element opacity optimized, non-intrusive to viewfinder
- Composition guide animation smoothness
- #5AC8C8 cold cyan as the only accent color

### Changed
- All status colors changed to restrained versions (dark mint/amber/coral)
- Guide arrows and text colors downgraded to dark tones
- Border lines refined (1.5dp → 0.8dp)

### Technical
- CameraX camera framework
- Custom OverlayView drawing layer
- Material3 DayNight theme
